## Les mots de la maison

- **Lot** : un ensemble de commits poussé sur master en une fois, après une passe complète verte.
- **Passe** : la batterie de contrôles d'un lot avant le push (ci-dessous).
- **Lib** : `librag3db.so` et l'extension `libvector.rag3db_extension`, bâties depuis un commit du
  moteur et rangées dans le **magasin** `~/.cache/rag3db-libs/<id>`, nommées par leur **dernier commit
  moteur** (sous `src/` ou `extension/vector/`), pas par la tête demandée. **`courant`** est le lien du
  magasin vers la lib en service.
- **Bascule** : changer `courant` aux deux postes et redémarrer les hôtes sur une lib neuve
  (`docs/procedures/bascule-de-lib.md`).
- **Hôte** : le démon `rag3weaver-backend` qui sert les backends (port 7970), tenu par la session G.
- **Témoin** : un test qui prouve une propriété ; **rouge d'abord** : on le voit échouer sans le
  correctif avant de le voir passer avec.
- **e2e** : les suites de bout en bout, `extension/rag3weaver/tests/e2e_*.rs`, toutes `#[ignore]`,
  montées dans un seul binaire (`tests/e2e/main.rs`, régénéré par `python3 tests/e2e/generer.py`
  après l'ajout d'une suite).
- **Instantané** (de bascule) : copie reflink d'une base avant qu'une lib neuve la touche, avec sa
  recette de retour `RETOUR.sh`. **L6** : l'instantané de lecture pris par chaque appel d'outil (une
  transaction `READ ONLY`).
- **Les deux sens** : une relation est rangée deux fois, une par sens ; `tools/check_rel_directions`
  vérifie qu'ils s'accordent.

## Le poste : `poste lourd`, `poste push`, `poste mesure`

`~/.cache/rag3weaver-build/poste` sérialise les travaux lourds de chaque poste :
- `poste lourd timeout <durée> <commande>` : au plus N lourds à la fois (1 au portable, 4 à 6 à
  luciepc), en file ; **la borne de durée dans le lourd**, jamais devant (sinon elle compte l'attente).

  bloque tous les lourds neufs** : ne la lancer que file vide.
