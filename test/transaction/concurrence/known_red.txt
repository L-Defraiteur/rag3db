# La passe compare le résultat à cette liste (test ctest concurrence_test.known_red) :
# un rouge absent d'ici, un nom d'ici qui passe au vert, ou un rouge connu dont les
# étiquettes changent (un rouge qui change de cause) la font échouer. Un échec sans
# étiquette (plantage, préparation qui échoue) compte comme « untagged ».

# rouges sur combien de passes), quand on la découvre variable. Jamais retirée en silence
# (orchestration, 5 octobre). Un rouge probabiliste est une étape : on cherche ce qui le rend
# constant (un seul fil, une graine, des délais choisis) avant de le laisser là. Les cas
# probabilistes sont dans probabilistic.txt.
